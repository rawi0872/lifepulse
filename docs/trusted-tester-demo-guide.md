# Life Pulse Trusted Tester Demo Guide

Use synthetic or demo-safe data only. Do not expose private tester data during a live demo.

## 5-8 Minute Narrative

1. Open `/nextron` and introduce NEXTRON as the Life Pulse command center.
2. For a new account, explain a situation naturally: certification exam, training three times a week, and launching a small portfolio site.
3. Let NEXTRON form the Life Setup Draft. Point out priorities, goals, starter habits, projects, initial tasks, and deliberately omitted items.
4. Correct one item conversationally so the audience sees that setup is editable before any write happens.
5. Build the bounded Action Plan. Show that permissions are separate from approval.
6. Approve the preview. Show Goals, Habits, Projects, and Tasks populated from canonical data.
7. Open Today and NEXTRON Noticed. Explain that Attention is deterministic and current-state based.
8. Ask NEXTRON: "What should I focus on?" Show grounded rich UI when personal context is relevant.
9. Ask for a small safe change, such as creating a Task. Approve it through the action proposal card.
10. Open `/life-map`. Show Goal -> Project -> Task and Goal -> Habit relationships.
11. Ask: "Why does this task matter?" Emphasize that canonical relationship facts are explicit, not inferred.

## Presenter Notes

- Do not promise autonomous behavior, background AI, notifications, or Calendar writes.
- Use the words "requires your approval" when explaining actions.
- If the account is sparse, frame empty states as intentional starting points.
- Keep NEXTRON positioned as bounded personal intelligence, not an omniscient assistant.
